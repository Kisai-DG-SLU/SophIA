Privacy Policy

SophIA applications using Google APIs — last updated: November 16, 2026 — Version française

Scope

SophIA is an open-source AI platform that each organization hosts and operates itself. Some of its applications use Google APIs. They are private applications: they are neither sold nor offered to the public, and they only serve the organization that hosts its SophIA instance. This page describes which Google data they access and what they do with it.

Google data accessed

Google Drive

  • Access to Google Drive is limited to the drive.file scope: the application can only access files it created itself. It does not see, read or modify any other file in the Drive.

Google Calendar

  • The application reads the list of calendars and their properties (name, colors, event labels).
  • It reads the events of these calendars: title, start and end, location, visibility, status, recurrence and color. Event descriptions and guests are never kept.
  • It adds an event only at the request of a user of SophIA, after their explicit confirmation, and only in a calendar owned by the authorizing account. It does not modify or delete any existing event.

No other Google account data is requested: no email, contacts or photos.

How the data is used

Google Drive

  • The application writes files only to the Drive of the user who authorized it, and only reads back those files.
  • The application may share these files with other people, or by link, only as configured by the user in SophIA.

Google Calendar

  • The events read are used only to show SophIA users their reminders and to answer their questions about their schedule, according to the access configured in SophIA.
  • A copy of these events is kept on the infrastructure of the organization that hosts SophIA. It is updated every few minutes: an event changed or deleted in Google is changed or removed from the copy at the next update. The copy holds an event only as long as it exists in Google.

For all applications

  • Data received from Google APIs is processed only on the infrastructure of the organization that hosts SophIA, including by AI models it hosts itself. It is not used to train AI models.
  • Authorization tokens are stored on that infrastructure and are used only for these operations.

Sharing

No data is collected beyond this operation. Apart from the sharing configured by the user, no data is sold, rented, shared with third parties or used for advertising.

Compliance with Google policies

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions. The application then loses access to the Drive or the calendar. Files and events already created remain in the user's Google account, and the user can delete them. The copy of calendar events is no longer updated, and it is deleted on request to the contact address below.

Contact
