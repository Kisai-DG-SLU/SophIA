Privacy Policy

SophIA applications using Google APIs — last updated: November 15, 2026 — Version française

Scope

SophIA is an open-source AI platform that each organization hosts and operates itself. Some of its applications use Google APIs. They are private applications: they are neither sold nor offered to the public, and they only serve the organization that hosts its SophIA instance. This page describes which Google data they access and what they do with it.

Google data accessed

  • Access to Google Drive is limited to the drive.file scope: the application can only access files it created itself. It does not see, read or modify any other file in the Drive.
  • No other Google account data is requested: no email, contacts, calendar or photos.

How the data is used

  • The application writes files only to the Drive of the user who authorized it, and only reads back those files.
  • The application may share these files with other people, or by link, only as configured by the user in SophIA.
  • The authorization token is stored on the infrastructure of the organization that hosts SophIA and is used only for these operations.

Sharing

No data is collected beyond this operation. Apart from the sharing configured by the user, no data is sold, rented, shared with third parties or used for advertising.

Compliance with Google policies

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions. The application then loses access to the Drive. Files already created remain in the user's Drive, and the user can delete them.

Contact

For any question about this policy: contact@kisai.fr.
