Conditions d'utilisation

Applications SophIA utilisant les API Google — dernière mise à jour : 15 novembre 2026 — English version

Accès

Les applications SophIA qui utilisent les API Google sont des applications privées. Elles sont réservées aux membres de l'organisation qui héberge son instance de SophIA, et ne sont ni vendues ni proposées au public.

Absence de garantie

Les applications sont fournies telles quelles, sans garantie d'aucune sorte, notamment de disponibilité, d'exactitude ou d'adéquation à un usage particulier.

Responsabilité de l'utilisateur

L'utilisateur reste responsable des fichiers que l'application écrit dans son Drive et des partages qu'il règle dans SophIA.

Révocation

L'accès de l'application au compte Google se retire à tout moment depuis la page myaccount.google.com/permissions.

Données personnelles

Le traitement des données reçues des API Google est décrit dans la politique de confidentialité.

Droit applicable

Les présentes conditions sont soumises au droit français.
