# SOPHIA Website

This repository contains the source code of the SOPHIA website.

SOPHIA (Sovereign Orchestrator Platform for Holistic Intelligence Architecture) assembles open-source building blocks into an agentic AI platform that the organization hosts, governs and audits itself. Security comes from the architecture, not from the model.

The website presents:

- the vision of the project
- the architectural concepts
- documentation
- links to the public repositories

Official website:

https://sophia.kisai.fr

## Publication

- This public repository is a mirror: changes are made in a private working repository and mirrored here.
- The site is built by GitHub Pages (Jekyll, `jekyll-sitemap` generates `sitemap.xml`): every push to `main` goes live.
- Visible changes (text, layout, images) are reviewed on desktop and tablet before being merged into `main`.
